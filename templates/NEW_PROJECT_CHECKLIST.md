# New Project Setup Checklist

- [ ] Create private Git repository if content is internal.
- [ ] Copy this workspace skeleton.
- [ ] Rename/fill project metadata in `agent-workspace.json`.
- [ ] Tailor `AGENTS.md` to project rules.
- [ ] Fill `STATE.md`.
- [ ] Fill `TASKS.md`.
- [ ] Add initial `HANDOFF.md`.
- [ ] Record initial architectural decisions in `DECISIONS.md`.
- [ ] Add stable reference documentation under `docs/`.
- [ ] Decide which external system is authoritative for operational data.
- [ ] Add `.gitignore`.
- [ ] Confirm no secrets are committed.
- [ ] Test a handoff: have a second agent read only the startup files and explain the project/current next step.
